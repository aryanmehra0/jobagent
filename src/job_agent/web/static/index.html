How to go from search to application
  1. Upload your resume, confirm the extracted details, and set roles, locations and work preferences in Settings.
  2. Keep Dry run enabled and run all phases. The agent searches, scores matches, prepares PDFs and updates downloads.
  3. Check the search timestamp and source report. Choose Ready for review, then read each PDF and eligibility note.
  4. Use the job link for manual applications. Review any email draft and attach the matching PDF before sending it yourself.
  5. For supported public forms, turn off Dry run only when you intend to submit, then confirm the Live apply step.
